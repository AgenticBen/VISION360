Once the connector key (V360_MCP_KEY) is set, add it to the end of the URL as ?key=YOUR-KEY when you add the connector. The same key is the publish key the workflow editor asks for. Keep it to yourselves.

Claude (claude.ai and the desktop app)

  1. Open Customize → Connectors.
  2. Click + Add, then Add custom connector.
  3. Name it VISION360 and paste the connector URL. Click Continue.
  4. Under Authentication choose No sign in, then Add.
  5. In a chat, click + → Connectors and switch VISION360 on.

After this site gains new tools, switch the connector off and on again so Claude sees them.

ChatGPT

  1. Open Settings, then Apps & Connectors (called Connectors in some versions) → Advanced, and turn on Developer mode.
  2. Back on that page, click Create (or Add connector).
  3. Name it VISION360, paste the connector URL, choose No authentication, confirm you trust it, and create it.
  4. In a chat, choose Developer mode from the + menu and pick VISION360.

Developer mode needs a paid ChatGPT plan, and editing tools may be limited to Business, Enterprise or Edu workspaces. ChatGPT asks you to confirm each change. Menu names shift as OpenAI updates ChatGPT; OpenAI's help article “Developer mode and MCP apps in ChatGPT” has the current steps.

What the agent can do

  • Build new workflows: create a new form (blank or a copy), add and change sections (the pages of a form) and questions, publish it, then get its public link, QR code and flyer. It can also choose which workflow is the main site, and delete a workflow when you ask (it has to say DELETE).
  • Edit workflows: read any workflow and its versions, edit the draft (add, change, move or delete questions, follow-ups, answers and their effects), run the checks, publish a new version and revert to an earlier one.
  • Conversations: list conversations by workflow, status or date (not the answers themselves).
  • Requests: list your requests, reply on them, mark them in progress, needs you or done (done needs a short summary, which goes in the change log).
  • Change log and dashboard: add a change-log entry; read the 30-day numbers.

To have Claude work through your requests, ask it: “Use VISION360: work through my open requests, oldest first. Mark each one in progress, make the change, check it, then mark it done with a short summary.” To build a new form: “Use VISION360: create a workflow called spring-workshop for the April workshop sign-up with name, phone, preferred day and consent, publish it, and give me its link and QR code.” App changes that need code are marked “needs you” for a coding session.
